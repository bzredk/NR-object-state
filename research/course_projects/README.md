## Elastic surface interaction

Nadia shared a former student's MEAM 6230 project as an example of estimating elasticity and using it in contact control. Its report and poster describe the same course project; they are separate from the published-paper collection.

| Source document | Role |
| --- | --- |
| `MEAM_6230_final_project.pdf` | Project report: method and experiments |
| `6230_final_proj_poster.pdf` | Poster: overview of the same project |

The original PDFs remain outside the repository. Only reference notes are published here.

The useful pattern is **probe -> estimate stiffness -> use the estimate for contact control**. The example uses a simple spring-based surface in simulation. Our 2D FEM study must distinguish effective contact stiffness from material modulus and validate predictions on a new interaction.

See the [Nadia feedback notes](../meetings/2026-11-13-nadia-feedback.zh-CN.md) for the source context, the report discussion and the proposed connection to our experiments.

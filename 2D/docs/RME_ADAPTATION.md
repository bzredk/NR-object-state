## Original inference mechanism

| Component | Verified definition |
| --- | --- |
| Target | **Paper:** added payload mass and three center-of-mass coordinates, treated as constant within one estimation window. Sequential changes trigger another estimation. These are not evolving viscoelastic internal fields. |
| Input | **Paper:** 200 joint-position/torque samples over 200 ms become 20 six-dimensional pseudo-wrench tokens. **Code:** VI first selects 50 samples; the network then selects 20 from those. The damped Jacobian conversion uses `(J J^T + 0.01 I)^(-1) J tau`. |
| Encoder | **Code:** Conv1D, 6 to 64 channels, kernel 5, padding 2, stride 1; learned positional tensor `(1,20,64)`; 8-head attention at width 64; mean pooling of attention outputs. No convolution activation, residual connection or layer normalization appears in this implementation. |
| Regression head | **Code:** one `64 -> 256 -> 64` block with ReLU and dropout 0.1 is applied three times with shared weights, followed by `64 -> 4`. Its parameter count is 53,252, matching the paper. |
| Supervision and normalization | **Paper:** MSE supervision, 350 simulated parent trajectories augmented to 1,050 shifted windows; 840/210 train/validation windows; learning rate 0.0001; 50,000 iterations; reported training time 1 h 26 s. **Code:** inference subtracts saved mean tensors and divides by saved standard-deviation tensors. The inspected release does not establish the training optimizer, batch size, normalization-fit axes, or a parent-group split manifest. |
| Prior | **Paper/Code:** Gaussian mean is the network prediction of the same observation window. Fixed physical-parameter standard deviations are `[0.5, 0.02, 0.02, 0.05]` in kg/m units. |
| Variational family | **Code:** a diagonal Gaussian with four means and four log standard deviations. The network also initializes its means. Initial log standard deviations are `[1.0,0.05,0.05,0.1]`; these values must not be mistaken for standard deviations. Original samples are not bounded or clipped. |
| Physical likelihood | **Code:** predicted gravity wrench is mapped to joint torques using the Jacobian and end-effector rotation. It uses mass and rotated CoM, not a full identified payload inertia tensor. The log likelihood sums Gaussian log densities over joint/time samples. Each torque-noise scale is `max(0.25 * window_range, 0.1)` N m. |
| Optimization | **Paper/Code:** reparameterized Gaussian samples and an ELBO. **Code:** one Monte Carlo sample per step, JAX automatic differentiation, Adam 0.025, global gradient clipping at 1, at most 2,500 steps. After iteration 700, checks every ten iterations stop after two small parameter changes below 0.04 in L2 norm. The random key restarts at 1 for each call. |
| Timing | **Paper:** 226 ms average estimation over 60 static experiments on an i7-11700K; approximately 400 ms adaptation accompanies a 200 ms acquisition window. **Code:** explicit compiler/model warm-up; README describes about 200 ms inference. These scopes do not establish cold-start latency or a FEM runtime target. |

Code anchors: [sampling and initialization](https://github.com/mateusz-jaszczuk/RapidMismatchEstimation/blob/a2fe683ccc7a921692949445f867a73938933d89/RapidMismatchEstimation.py#L39-L79), [VI objective and stopping](https://github.com/mateusz-jaszczuk/RapidMismatchEstimation/blob/a2fe683ccc7a921692949445f867a73938933d89/RapidMismatchEstimation.py#L82-L164), [encoder and normalization](https://github.com/mateusz-jaszczuk/RapidMismatchEstimation/blob/a2fe683ccc7a921692949445f867a73938933d89/RapidMismatchEstimation.py#L167-L219), [gravity torque prediction](https://github.com/mateusz-jaszczuk/RapidMismatchEstimation/blob/a2fe683ccc7a921692949445f867a73938933d89/RapidMismatchEstimation.py#L268-L276).

## Paper/code distinctions that affect adaptation

1. Figure 2's caption describes an input width of 64, while Eq. 11, Table 4 and code agree on six input channels; 64 is the convolution feature width. The body describes three MLP blocks without explicit weight tying; released code reuses one block, consistent with its reported parameter count. Pooling is over attention outputs, despite the caption's wording about scores.
2. The paper's nominal 200-to-20 input reduction does not describe the released 200-to-50-to-20 path. `convert_VI_inputs` also requests a final index equal to `N`, outside `0..N-1`; runtime handling depends on JAX indexing. No crash or numerical effect is asserted without executing that stack. The 2D adapter must use valid causal indices and retain its actual sample-count record.
3. Appendix A's force-direction checks and the released detector differ: the code repeats an x-component comparison and omits some absolute values. The detector, nominal robot controller and compensation are outside this 2D inference comparison.
4. **Implication:** the neural prior and likelihood both depend on the same data. Its ELBO is a useful data-conditioned inference objective, but does not by itself guarantee Bayesian calibration. An inaccurate network mean can still change the objective through the prior, even if optimization converges.

## Original method to project adaptation

| Original RME | Required 2D adaptation |
| --- | --- |
| Four window-static payload parameters | The same six nonnegative coefficients as TRF, defined at the **window start**. All methods then propagate the complete internal field with the same actual motion and FEM. |
| Pseudo-wrench sequence and robot kinematics | Permitted motion, force, optional lateral markers, time and channel masks. Closed channels must also be absent from normalization, initialization and likelihood. No fake repeated-frame history. |
| Original fixed-width encoder | Preserve Conv1D, learned position information, attention and regression as the architectural reference. Adapted widths, heads, sample counts and padding are recorded; they are not an exact network reproduction. |
| Simulated payload labels | Identical projected window-start internal-field labels and physical training histories for every learning model. Projection error, basis rank/conditioning and a projected-truth reference identify representation limits. |
| Unbounded physical-parameter Gaussian | Respect the common coefficient support. A shared bounded bijector can transform both prior and mean-field variational distributions; include its density correction, or use the invariant Gaussian KL in the common unconstrained coordinates. Clipping samples while retaining the original density is invalid. |
| JAX differentiable gravity likelihood | The unchanged SciPy FEM history-observation likelihood. A custom derivative interface must be checked against finite differences, including contact-switching cases; it is a declared implementation change. No undisclosed surrogate or detached likelihood. |
| Network-conditioned prior | Compare prior-only output with VI, a fixed training prior with VI, and shared network initialization for TRF in representative conditions. These isolate offline prior information, refinement and optimizer choice. |
| Robot compensation and passivity experiments | Future force/shape prediction and inference cost only. Reusing a state for Slow/Fast press does not establish closed-loop control gain, passivity or real-time feasibility. |

The original likelihood sums sample log probabilities. Reusing TRF's sample-normalized residual as a VI likelihood would change its effective strength relative to the prior; any tempering must be explicit. Observation noise and representation mismatch must be selected on training/calibration data, not tuned on final tests.

Use independent variational seeds and report the definition of the point prediction, Monte Carlo prediction cost, proper predictive scores, coverage and width. State uncertainty and future measurement noise are different outputs. The same-window neural prior supplies no automatic calibration guarantee, especially in weak-information waiting intervals.

## Implemented VI interface

[`variational.py`](../src/nr2d/variational.py) uses six-dimensional Gaussian logits and the shared transformation `c = 2.5 sigmoid(z)`. The variational distribution starts equal to the supplied prior. A prior center exactly at a coefficient boundary is mapped to a finite logit using a recorded endpoint fraction of `1e-6`; random samples are never clipped. The negative ELBO combines the summed FEM observation NLL with the exact Gaussian KL. A custom Torch backward uses the implicit derivative from [`WindowProblem`](../src/nr2d/inference_physics.py); SciPy is not assumed to support automatic differentiation.

The default function budget is 12 Adam steps at learning rate 0.05, one likelihood sample per step and gradient clipping at norm 10. Experiments record their actual calibrated budgets and prior scales. Completing a fixed budget is not reported as convergence. Returned point coefficients are the physical distribution mean evaluated by 64-point marginal Gauss-Hermite quadrature. Sixteen independently seeded coefficient samples are returned by default. VI runtime includes these operations; encoding, subsequent replay and future prediction require additional timing.

The physical mean of a transformed Gaussian differs from transforming its latent mean. Therefore a no-VI prior-distribution mean control uses the same quadrature convention as VI; the raw neural center remains a separate point-prediction ablation. This prevents a change of point summary from masquerading as likelihood refinement.

[`test_variational.py`](../tests/test_variational.py) checks the full physical backward path, transformed-density KL cancellation, sample support, and prior preservation under a constant likelihood. A full-grid calibration-history ELBO check passes finite differences. Local verification records in `2D/.runtime/inference-environment/vi-checks.json` and `vi-contact-switch.json` additionally identify piecewise contact derivatives; no centered derivative is asserted at the exact switching boundary. These are interface and calibration checks, not independent test-performance evidence.

The constant-likelihood unit uses an exactly convenient scale of 0.5; it does not establish exact prior preservation for arbitrary scales. A post-hoc check with the actual RME-128/seed-11 scale vector and calibrated multiplier 0.3 found initial KL roundoff gradients of about `2.2e-16`. Eight frozen Adam steps amplified them to a maximum log-scale change of 0.00862 (about 0.86%) and physical coefficient-mean change of `3.22e-6`, with no latent-mean change. In pilot 14000's force-only 0.2 s waiting window, every sampled physical-likelihood gradient was exactly zero, and the final distribution was bitwise identical to the constant-likelihood run. See [the diagnostic record](../runs/inference/methods_20261030/verification/weak_prior_numerical_drift.json). This small numerical floor is retained in the frozen results; tiny VI/prior differences there are not observation evidence or exact-prior-preservation evidence. No algorithm or hyperparameter was changed after this diagnosis.

Q3 also requires a finite-sample qualification: the frozen force bands use linear empirical 5th/95th quantiles of only 16 trajectories. In an independent, correctly specified Gaussian reference with 200,000 draws, this same rule covered 80.66% of targets (Monte Carlo 95% interval 80.49-80.83%). Its empirical CRPS was 0.59983, matching the finite-ensemble expectation `(1+1/16)/sqrt(pi) = 0.59945`, rather than the underlying Gaussian's expected score 0.56419. Consequently, force-band coverage below 90% cannot alone establish posterior miscalibration. This Gaussian diagnostic is not a distribution-free correction for nonlinear FEM responses or their zero-force atom, and it does not explain low coefficient coverage, which uses analytic transformed-Gaussian quantiles. The frozen primary scores and intervals are unchanged. [Reference results](../runs/inference/methods_20261030/verification/finite_mc_reference.json); reproduce after timing with `python tools/check_monte_carlo_metrics.py` from `2D/`.
